Alive Luxury Retreats: UI/UX Audit

This is a full audit of the Next.js rebuild of Alive Luxury Retreats. It lists every alignment, spacing, imagery, congestion, accessibility and performance problem we found. Each item has a severity, where it appears and a concrete fix. The last section covers the deploy-size work that was done for Vercel.

Date: 16 Oct 2026 Build: local production build (next build / next start) Viewports: 1440 × 900 desktop · 390 × 844 mobile Method: Vercel Web Interface Guidelines + real-scroll screenshots + in-browser measurement

We audited 14 representative pages at both widths: home, about, Bali, Spain, anxiety, programs, FAQ, blog, a blog post, contact, get-a-quote, book-online, NDA and search. Together they use every page template on the site. We captured screenshots while scrolling, so the GSAP reveal animations fired the way they do for real visitors. A script measured image crop and upscaling, font sizes, tap targets, line length and page height. We also reviewed the code in src/ line by line against the Vercel Web Interface Guidelines.

Fix status: 16 Oct 2026 (second pass)

Most findings below have now been fixed in the code. The production build passes and the full QA crawl is clean. Re-measuring the same 14 pages at both widths: upscaled images fell from 106 to 2, tap targets under 44px from 284 to 4, and the mobile home page is 20% shorter (27.0k → 21.7k px).

Not fixed yet (needs your input):

  • Photography: the AI-looking scenes and mixed portrait styles need real photos supplied. Code can only crop and frame what exists.
  • Review cards: these are still images of text. The full review text isn't in the source content, so it can't be typeset. The home quote is still cut off for the same reason.
  • Script font licence: the file is named "personal use". Confirm the licence or swap the font.
  • Duplicate package PDF: the two near-identical 9.4 MB PDFs. Keep one or host them externally.
  • Length of Spain, Bali and Programs: these pages still run 14–24k px on desktop, because more generous section spacing offset the layout savings. Making them shorter means cutting content.
  • Full-bleed photo heroes on mobile: these still crop landscape photos, since the picture has to fill the screen behind the text.

Top 10 priorities

  1. Too many fixed buttons on mobile. The bottom action bar, a floating WhatsApp button and a back-to-top button cover about 140px of every mobile screen and sit on top of text. WhatsApp appears twice.
  2. Pages are far too long and repetitive. The home page is 27,000px on mobile (about 32 screens) and Spain is 33,500px. The same blocks (pillars grid, reviews, call-back form, footer form) repeat on most pages.
  3. Images are cropped or stretched. Landscape photos sit in tall portrait frames, losing up to 75% of the picture. A 980px photo is stretched to 1308×1634. The sizes values are wrong, so retina screens get soft images.
  4. Mixed photography styles. Obvious AI-generated scenes, a studio cut-out portrait on white, a black-and-white headshot, a Google search-result screenshot and photographed text testimonials all appear together. This undercuts the "luxury" positioning.
  5. Text contrast is too low. The olive and gold small text (kickers, subtitles, meta, labels) is 2.0–3.2:1 against the background, and the focus ring is 2.0:1.
  6. Text is too small. Form labels are 10.2–11.5px, kickers 10.9px, and the mobile brand name 11.2px.
  7. Large empty half-columns. Very long checklists sit beside a sticky image, so half the screen is blank for screen after screen (Spain, Bali, and the home pillars).
  8. Too many CTAs. One viewport can show 3–5 different calls to action, and two near-identical forms (request booking and custom package) appear together.
  9. Content errors. The Spain page lists a "Traditional Balinese welcome ceremony". The page says "three levels" but shows two. A testimonial is cut off mid-sentence. Text like "retreat......" and "(PDF):www…" appears on the page.
  10. Licensing risk on the script font. The "Renew Me / alive" script font file is named breathing-personal-use…. Confirm there is a commercial licence before launch.

1. Site-wide: layout, type and color

High

Olive and gold small text fails contrast

Token --olive #968d4b is 3.18:1 on ivory and 2.91:1 on sand. --gold #bab37d is 2.01:1. It is used for the hero subtitle (home.module.css:24), .kicker (globals.css:401), blog meta and crumbs, booking kicker, FAQ numbers, the header tagline, search kinds and contact channel labels.

Add an --olive-text: #6e6630 token (≥4.5:1) and use it for all text. Keep the light olive and gold only for rules and ornaments.

High

Focus ring is almost invisible

globals.css:116–119. The gold-bright #c9b200 ring is 2.01:1 on ivory and 1.83:1 on sand.

Use --ink or --gold-deep for the ring on light surfaces, and keep gold-bright only on dark sections.

High

Text is too small to read comfortably

Footer form labels are 10.2px (LeadForm.module.css:57). Form labels are 11.5px (globals.css:321). Kickers such as "Service Information" are 10.9px. Mobile QuickBar labels are 10.9px. The mobile header brand name is 11.2px. Blog meta and tag chips are about 11.5px and 9px.

Set a 12.5px minimum for uppercase micro-labels and 14px for anything a user must read (labels, meta). Reduce letter-spacing on the small caps.

Medium

Heading sizes have no consistent scale

H1 is 56.6, 64, 72.6, 97.3 or 103px depending on the page. H2 is 21.6, 26.4, 27.2, 30.6, 32.8 or 46.6px. H3 is 17.9–32px. There are 32 distinct rem font sizes and 77 distinct clamp() expressions.

Define a 6–7 step type scale (for example --step-0…--step-6) and map h1, h2, h3, kicker and body to it. Use one H1 size per template type (hero vs. utility page).

Medium

Spacing has no system

There are about 101 distinct px values and 25 breakpoints with mismatched pairs (759/760/767/768, 899/900, 999/1000, 1099/1100, 1239/1240). Section padding is clamp(28px,3vw,46px) (globals.css:60), which is tight for a luxury layout. Meanwhile, sticky columns leave whole screens empty.

Create --space-1…8 and --bp-sm/md/lg tokens. Set section padding to about clamp(56px,8vw,120px) and use it consistently.

Medium

Mixed visual language

Buttons, inputs and cards have square corners. Photos have 20px rounded corners, portraits are 50% circles, and some leftover rules set 999px "arches" that are later overridden (home.module.css:30 vs 48, Blocks.module.css:47 vs 172, Groups.module.css:45 vs 80). Teal bullets, checkmarks and USP text clash with the gold palette.

Choose one radius scale (for example 0 for UI and 12px for media) and delete the dead overrides. Replace teal accents in content with olive-text or ink, and keep teal only for WhatsApp and utility actions.

Medium

Heading case is inconsistent

Examples: "Choose Your Level of Luxury & personalisation", "what types of anxiety issues does alive help me re…" (anxiety H2, all lowercase), "DOWNLOAD RETREAT PACKAGES & PRICING" (Spain H2, typed in caps), "Not sure? Speak to … Book Your retreat……" and the H1 "Book A Consult - Select Day & Time" (hyphen used instead of a dash).

Normalise heading case at build time (in build-content.mjs), convert .../...... to …, and use an en dash in titles.

Medium

Paragraph sizes alternate inside the same text

On blog posts and the home intro, single-line paragraphs render at about 17–19px and multi-line ones at about 15–16px. The article looks like it was set in two fonts.

Use one body size (17px desktop, 16px mobile) for all article paragraphs. If a "pull line" style is needed, make it explicit.

Low

Header logo is barely visible on dark heroes

On Bali, Spain and other photo heroes, the small gold logo at the top left is lost against the image. The logo also uses a raw <img src=smallest> with no srcset (Header.js:192), so it is soft on retina.

Use a light or white logo variant when overlay is true, at least 40px tall. Render it with Img sizes="86px".

Low

Footer is cramped

Footer links are about 21px tall with a 3px gap. Social icons are 30×30. Legal links are 0.78rem. Two-column link lists use nowrap and overflow between 760 and 1100px (Footer.module.css:31–32). The script "alive" before each column title adds visual noise.

Give links 44px tap rows (padding), make icons 44px, use minmax(0,1fr) and allow wrapping, and drop the script prefix or keep it only on the first column.

2. Congestion and page length

High

Three fixed layers cover mobile content

QuickBar (Email, Info, Call, WhatsApp, about 60px), a floating WhatsApp button (about 52px) and a back-to-top square stack at the bottom of every mobile page. They cover body text and cut off USP labels ("Exclusive Access To World Class Te…"). WhatsApp appears twice.

On mobile, remove the floating WhatsApp button (the bar already has it) and move back-to-top into the bar or drop it. Add padding-bottom equal to the bar height plus env(safe-area-inset-bottom) to body.

Pages are extremely long

The same blocks repeat across pages: the "Complete System" panel, the 16-image four-chapter pillars grid, the call-back form, the reviews pair, the news strip, the personalised-support block, the custom package band and the footer.

Cap landing pages at about 8–10 sections. Collapse the pillars into one 4-card row (one image per chapter) with a "See the full program" link. Show reviews once, and show only one lead form per page.

High

Too many competing calls to action

The home "Personalised Support" block alone has a WhatsApp button, "Speak To A Retreat Advisor", a booking card with "Book Now", the custom-package form below it, plus the bar and FAB. Get-a-quote has "Request a booking" and "Request a custom package" forms, with the same fields, about 600px apart.

Medium

Very long checklists leave half the screen empty

Spain's inclusions list has about 40 rows in a single right-hand column with an empty left half for over two screens. Bali's accommodation features have 20 rows beside a short sticky image. The home pillars have a sticky "01/02/03/04" label with an empty 240px column.

Group the inclusions into 3–4 categorised columns or cards, or put them in an accordion. Size sticky images to the list height, or switch to a 2-column list under the image.

Medium

Scroll-scrubbed fades make content unreadable

On the "A Complete System for 360 Transformation" list, rows fade in as they scroll, so half the list sits at 20–40% opacity at any moment. The ocean banner's split-text heading is clipped at the bottom ("FOR YOU" cut off) on both desktop and mobile.

Reveal each row once at full opacity (no scrub). Give the split-line mask padding-bottom:.15em so descenders and caps aren't clipped.

Medium

Busy hero layering

On the home hero, the small inset image overlaps the bottom of the hero and spills into the next section. The beige panel behind the main image ends about 90px above the left column's CTA, so the two halves don't share a baseline.

Keep the inset inside the hero bounds and align the panel bottom with the CTA row (or remove the panel).

3. Unsuitable, cropped and low-res images

High

AI-looking and mismatched photography

Home pillars and the news strip use visibly AI-generated scenes (meeting room with laptops, IV-drip by the pool, a man at a waterfall, a group shot with repeated faces). They sit next to real resort photography, a studio cut-out portrait on pure white (Skye), and a black-and-white headshot (Book-online). The Bali service collage includes a heavily blurred foreground figure.

Use real photography of the actual villas, team and treatments wherever it exists. Grade all images to one warm look. Put all portraits on the same background with the same crop and corners.

High

Testimonials shown as pictures of text

The review carousel cards are images of text (Groups.js:189) whose text renders at about 7px. Their alt is only the attribution, and the same review also appears in the quote slider above. A Google search-results screenshot is used as a "1000+ reviews" badge.

Render reviews as real text cards (quote, name, star icons). Replace the screenshot with a typeset "4.9 ★ · 1,029 Google reviews" badge linking to the profile.

High

Landscape photos forced into portrait frames

Page-head media and editorial boxes are 631×930 (portrait) but are filled with panoramas. Bali c014631d… (1882×836) loses 70% of the frame (3.3× crop). Spain heroes are cropped 2.6×. On mobile, full-bleed sections of 390×861 crop landscape images 3.3–3.9×. The Food section crops the chef's face at the frame edge.

Use landscape (4:3 or 3:2) frames for landscape assets, or use aspect-ratio from each image's metadata. Set object-position for people shots.

High

Upscaled, pixelated images

On Spain, f4818c4f… (source 980×660) is stretched into a 1308×1634 box. On Programs, 9aaf1d2d… (source 201×251) is shown at 354px. On FAQ, the hero image dc664257… (1024²) fills 457×571 and looks soft on retina. Spain's spa and food images show visible compression.

Don't use sources under about 1.5× their display width. Replace these with higher-resolution originals or make the frame smaller.

Medium

sizes attributes are too small, so retina gets soft images

Pillar cards declare 22vw (316px) but render at 460px (Groups.js:121). Blog cards declare 25vw (360px) but render at 417px (Groups.js:232). Program cards declare 22vw but render at 407px. The diagram declares 34vw (489px) but renders at 540px. On 2× screens the browser picks a 640w file for a box that needs 920w.

Match sizes to the real column widths, for example (min-width:1100px) 460px, (min-width:700px) 45vw, 100vw.

Medium

Images inside blog articles crop out the subject

Article images are cropped to fixed boxes. For example, the woman holding a cup shows only the back of her head, and the beach walker is cut at the knees.

Let in-article images keep their natural aspect ratio (height:auto), with a maximum height.

Low

Decorative and missing alt text

11 home images and 10 of 12 blog images have empty alt. Most are fine (the card title is next to them), but the hero and support portraits should be described. Review images need their quote text in alt (see above).

Audit alt text per section: decorative images stay alt="", content images get a description.

4. Home page

Medium

Program focus cards don't line up

The three columns (Renew, Revitalise and Restore Me) have different copy lengths, so the "Renew me / Revitalise me / Restore me" links land at different heights (y = 385, 361 and 392). The section intro paragraph starts above the H2 instead of aligning with it. The "01/02/03" labels on the photos are white 10px text that is barely visible.

Use display:grid; grid-template-rows: subgrid (or flex column with margin-top:auto on the link). Align the intro to the H2 baseline and drop or enlarge the number labels.

Medium

Two dark photo sections back to back

"Download Retreat Package & Pricing" (dark beach photo) runs straight into "A Complete System…" (dark palm photo). The form card sits on a third dark tone. It reads as one heavy block.

Put a light section between them, or merge them. Give the form a light surface.

Medium

USP strip

The faint sunburst icons are nearly invisible. Teal subtitles clash with the palette. On mobile, the 2-column grid leaves the fifth item on its own, and "Life Changing" wraps so its baseline doesn't match "Expert". The white background breaks the ivory flow.

Use a 5-up row on desktop and a horizontal scroll or a 2-2-1 layout with a centred last item on mobile. Use ink or olive-text subtitles and an ivory background.

Medium

Text over the photo's subject in the ocean banner

The centred heading and lines sit directly on top of the paddle-boarder, the only point of interest in the image.

Use object-position to move the subject off the text block, or shift the text to one side.

Medium

Accommodation copy contradicts the layout

One line says "we offer 2 unique levels". The next block says "three tailored levels", but only two cards (Level 01 and 02) are shown. The "View Package" button floats right, away from the heading. The "Luxury Private Accommodation" H2 sits directly on the paragraph with no gap.

Make the copy match the two levels shown, put the CTA under the intro, and add heading-to-body spacing.

Medium

Reviews block

The large quote is cut off mid-sentence ("…turn someone's life around with so"). There are two carousels with separate arrow sets. The third card is clipped at the viewport edge with no peek affordance on the left.

Use the full testimonial, keep one carousel, and show consistent peek/edge fades.

Low

News strip proportions

The featured post image is 456px wide but the side posts use 190px thumbnails with long four-line titles, so the side column is uneven and top-heavy.

Use a 1 + 2 layout with equal-height side cards (image on top) and clamp titles to 3 lines.

5. Location pages (Bali, Spain)

High

Wrong content on the Spain page

Spain's inclusions list "Traditional Balinese welcome and blessing ceremony" and "Optional Private Healing Sessions including Balinese healing". The FAQ-style heading "What is the food like at the alive health spa?" sits orphaned under the food list instead of above it.

Write Spain-specific inclusions and move the heading above its list.

Medium

Hero text readability over photos and video

On Bali, the uppercase Cinzel subtitle runs over a busy pool scene with a light overlay. On Spain, the H1 overlaps the swimmer, and the CTA floats right and doesn't line up with the subtitle's left edge. A stray 1px vertical scroll-cue line sits at x≈915px.

Add a stronger left-side gradient (from 0 to 55% ink), put the CTA under the subtitle, and anchor the scroll cue to the content grid.

Medium

Inline checkmarks inside paragraphs

Bali "Private Beachfront Pool Villas": "Your Private Luxury Space ✓ Enjoy your own… ✓ With private sleep… ✓ You have full privacy…" is a list crammed into one paragraph.

Split it into a real list at build time.

Medium

Collages misalign with the text column

The overlapping two-image collages start 130–240px below their section heading (for example Food From The Earth and Service & Experience), so text and image tops don't line up. The small overlapping image covers people's faces.

Align the media top with the H2, and place the inset over a non-subject area.

Low

Long centred intro paragraph

Spain's intro is a centred paragraph of over 300 characters (hard to read). The background alternates ivory, white and sand every section, which makes the page look banded.

Left-align body copy over two lines long, and alternate at most two surfaces.

6. Blog and articles

Medium

Drop cap on a one-line paragraph

Blog.module.css:31. The drop cap spans three lines, but the first paragraph is two words long, so the next lines wrap under it ("Driven." indented). It is also gold #bab37d at 2.0:1.

Only apply a drop cap when the first paragraph is longer than about 200 characters, and use olive-text color.

Medium

Three different left edges

On the post page, the title column starts at x=113, the cover image at x=46 and the article text at x=66. The sidebar kicker "Speak with the Alive team" floats 50px above its card.

Align the title, cover and body to one grid line, and attach the kicker to the card.

Low

Blog index hero

The "Alive News" H1 sits on a wide empty column while a small 333px image sits top right. The featured post title is 4 lines at 36px.

Use a text-only header (no image), or a full-width featured post as the hero.

Low

Tag chips

About 9–11px text, 33px tall, 8+ chips stacked in the sidebar.

Show 4 tags with a 13px minimum and 36px height, and move the full list to the end of the post.

7. Contact, quote, booking, FAQ and NDA

Medium

Contact channels

The email "BOOKINGS@ALIVELUXURYRETR / EATS.COM" breaks mid-word because it's set in uppercase Cinzel. The kicker "WhatsApp" is repeated in the value "WHATSAPP: +62…". The long CTA labels ("WhatsApp Here", "Call Here", "Email", "Quote") are generic.

Set contact values in the body font, without uppercase, with overflow-wrap:anywhere. Remove the duplicate prefix, and use specific labels such as "Message on WhatsApp" or "Email bookings".

Medium

Get-a-quote cards don't line up

Cards 1 and 2 are 245px wide, card 3 is 343px with a gold top rule the others lack. Cards 1 and 2 have about 120px of empty space at the bottom. Card 1 mixes a WhatsApp button with a "Call +1 478…" link that uses a different number.

Use three equal columns (or 1+1 above a full-width form) and the same card styling. Show one phone number with a country label.

Medium

Book-online list

Each row has both "Read More" and "Book Now". The "Interview" row has no description. Portrait treatments differ (see section 3). The hero uses the AI meeting-room image, which is unrelated to booking.

Make the whole row a link to details with one "Book" button. Add the missing description, use matching portraits, and use a calm, relevant hero image or none.

Medium

FAQ content artefacts

"Download the full retreat pricing guide (PDF):www.aliveluxuryretreats.com" has a missing space and a raw URL. An SEO page title, "Download Packages | Alive Luxury Wellness Retreats", is rendered as an H4. On first load all answers render open, then collapse after hydration (a layout shift).

Clean the copy, and server-render the panels closed (hidden or height:0).

Medium

NDA page

The page is 31 mobile screens of legal text. The sticky table of contents has only 3 entries because sub-clauses ("Disclosure of Confidential Information.") are plain paragraphs. The checkbox is 13×13px. The form is at the very bottom.

Promote the clauses to h3 so the table of contents is complete. Add a "Skip to signature" link at the top, and enlarge the checkbox and radio hit areas to 44px.

8. Accessibility and interaction (code review)

High

Split-text headings and lines are silent to screen readers

SplitText.js:17–18 with Blocks.js:53. aria-label is set on a <p> and all child text is aria-hidden. Paragraphs can't take a name, so many screen readers announce nothing.

Render <span class="sr-only">{text}</span> next to the aria-hidden split span.

High

Mobile menu dialog has no focus management

Header.js:102 and 215. It has role="dialog" aria-modal, but focus isn't moved in, trapped or restored. The close control is outside the dialog, and the page behind isn't inert.

Focus the first link on open, trap Tab, make main and footer inert, return focus to the burger, and add a close button inside the dialog.

High

Autoplay videos can't be paused

Hero.js:71 and Blocks.js:196. They loop forever, still play under prefers-reduced-motion, and have no pause control (WCAG 2.2.2).

Add a pause/play button, and show the poster only when reduced motion is on.

Medium

Form error handling is uneven

NdaForm.js:57–67 and 87–88, and BookingRequest.js:46–53 and 88–89. There is no aria-describedby, aria-invalid or live region, and focus isn't moved to the first error or to the success panel. Inputs have no name.

Reuse the LeadForm pattern (per-field errors, focus the first invalid field, a role="status" panel).

Medium

Hidden header traps keyboard focus

Header.js:172–176. The header slides away (yPercent:-100) on scroll, so focused links can be off-screen.

Reset it to 0 on focusin.

Medium

Touch targets under 44px

Footer social 30×30, footer links about 21px, NDA "Clear" about 28px, "Edit details" about 30px, .link-arrow about 32px, LegalToc links about 33px, and blog tags about 33px.

Use a 44px minimum hit area (padding or ::after overlay), and add touch-action: manipulation.

Low

Smaller semantic issues

aria-haspopup on plain disclosures (Header.js:51). role="region" on every FAQ answer creates dozens of landmarks (FaqBrowser.js:57). The Previous/Next labels repeat in each carousel (Carousel.js:40, 43). A literal "*" in labels is read as "star". Headings skip levels (Contact.js:134, Blocks.js:115, Editorial.js:25). Decorative numbers are announced (Groups.module.css:10, Contact.module.css:23).

Fix each as listed; all are one-line changes.

Low

Motion not gated

The scroll-cue animation runs forever even with reduced motion (Hero.module.css:65). Dropdown, mobile-group, QuickBar, LeadForm and Carousel tweens ignore reduced motion. Hover animates padding-left (a layout property) in 5 files. Header animates height, width and height on scroll (Header.module.css:7 and 30).

Use duration: reduce ? 0 : …, transform instead of padding, height and width, and animation:none in the reduced-motion block.

9. Performance (code)

Medium

LCP hero image hidden until JS runs

globals.css:354. [data-anim=clip] sets clip-path: inset(100%) on the priority hero images (page.js:41, PageHeadMedia.js:24, Hero.js:58, Blog.js:32). The hero stays blank until hydration plus a 1.5s tween.

Exclude hero media from pre-hiding, or start the animation from a partial inset that is already visible.

Medium

Unused font weights

layout.js:11 and 13. Cinzel loads weights 400/500/600 but only 400 is used. Barlow loads italic in all 3 weights but italic appears only in the header tagline. That is about 4 extra font files on every page.

Load Cinzel 400 only, and Barlow italic 400 only (or drop italic).

Medium

Scroll handlers force layout

LegalToc.js:17–22 calls getBoundingClientRect() on every heading on every scroll frame. Carousel.js:18 calls setEdge({...}) on every scroll event. Header.js:172 calls matchMedia on every update.

Use an IntersectionObserver, update only when a value changes, and cache the media query.

Low

Minor issues

The second home hero image is lazy-loaded even though it is above the fold (page.js:46). will-change: transform is set permanently on every split word (globals.css:202). 'use client' in lib/gsap.js does nothing. There is no color-scheme meta. Dates are hard-coded to en-GB.

Make that hero image eager, set and clear will-change in GSAP callbacks, add colorScheme:'light' to the viewport export, and use Intl.DateTimeFormat(undefined,…) on the client.

Method notes: the screenshots were taken while scrolling with real mouse-wheel events, so the GSAP ScrollTrigger reveals had fired. Contrast ratios were computed with the WCAG 2.1 formula from the CSS tokens in globals.css. Crop factor = max(natural ratio ÷ box ratio, box ratio ÷ natural ratio); above 1.8 means more than 45% of the photo is cut away.
